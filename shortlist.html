How to use this tool

  1. Import: Save menu → Import updated list. Only new participant numbers are added; people already here never change. In the CSV, participant_no is a plain number and multiple timeslots are separated by ;.
  2. Auto-place (wand beside New / unplaced) fills the empty slots you tick, using your screening criteria. Undo it with the ↶ button or Ctrl/Cmd+Z.
  3. Adjust: drag cards between slots, Backups and Rejected. Click a participant no. to edit availability. Click the round icon to set status and copy the message to send.
  4. Call script (top right of the stats bar) opens the phone script.
  5. Save: everything autosaves to data/state.json. The dot on the save icon is green when saved, red when not. Save CSV (all, or confirmed only) writes a snapshot to exports/; Copy shortlist copies confirmed participants only, as text.
Participant numbers only; names and contacts stay in your own lists.
